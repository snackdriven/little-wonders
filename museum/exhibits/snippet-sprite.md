A Chrome and Edge text-expansion project inspired by Text Blaze. Its README describes shortcut triggers, dynamic templates, form inputs and page actions, with snippets stored locally in the browser.

What begins as a way to avoid retyping a sentence grows into a little language: a date here, a condition there, perhaps a loop. The museum has resisted the temptation to write this plaque as a template.
