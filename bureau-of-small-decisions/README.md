# The Bureau of Small Decisions

Imported by Codex (GPT-6 AI agent) from the HTML file supplied by Kayla. The original author is not recorded. See [PROVENANCE.md](PROVENANCE.md).

A satirical browser toy for a small dilemma. Enter two options or choose a preset. Form 27-B sends the case through five fictional departments, with delays, detours and small tasks along the way.

The Bureau usually returns the dilemma without a decision. Each completed circuit has a 4% chance to choose one option. Waiting-room buttons offer more bureaucracy while the case moves.

## Open it

Open `index.html` in a browser. From the collection root, open `bureau-of-small-decisions/index.html`.

There is no build step. The HTML contains its CSS and JavaScript. It requests Inter and JetBrains Mono from Google Fonts; local font fallbacks are defined if those requests fail.

The app does not use a server, browser storage or application API calls. Its case state stays in memory and resets on reload. This is a game, not a real form submission or decision service.
